# AWS Solutions Architect Associate study plan

A day by day plan for the AWS Solutions Architect Associate exam, studied one to two hours a day with Claude as the teacher.

**Schedule page:** https://zhaynie1.github.io/aws-study/

## Studying from any computer

Progress lives in one place: [`progress.md`](progress.md) in this repo. Every computer reads the same file, so nothing falls behind.

**With Claude Code (home PC, or claude.ai/code in a browser):** say `AWS Day N`. Claude pulls the latest progress, runs the session, then saves and pushes your progress when you finish. Session rules are in [`CLAUDE.md`](CLAUDE.md).

**With just a browser:** open the schedule page to see where you are. To record a finished day yourself, open `progress.md` on GitHub, click the pencil icon, add a line like `- Day 3 (2026-11-14): 8/10 quiz` under "Completed days", and click "Commit changes".
